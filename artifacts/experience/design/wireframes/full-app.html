03 · Gap Analysis / Initial Path

State: diagnosed · Intent: understand the gap and choose a direction

PATH
Current → TargetCurrent band, target band, confidence, and skill gap.
Why this plan?Explain with concise evidence; do not make absolute claims.
Chấp nhận kế hoạch 30 phút/ngày→
Accept → create Daily Plan → Home shows one next best action. Edit → return to goal/time, without resetting placement.

04 · Today / Home

State: learning · Intent: know the most important task today

STUDY
Continue sessionIf a task is in progress, it always appears above Today's Plan.
Plan progressReview · Practice · Lesson; do not turn it into a dashboard with many cards.
Bắt đầu: Writing Task 2 · 25 phút→
No placement → CTA is Placement. No task → create a replacement micro-session.
Kế hoạch sẵn sàngChưa có kế hoạchTrốngNgoại tuyến

05 · Study Session

State: practicing · Intent: complete one specific outcome

SESSION
Goal + timerAlways know what you are doing, how much time remains, and what completion means.
WorkspaceSkill-specific: passage, audio, essay, or recording.
Lưu và kết thúc phiên học→
Pause/exit → save checkpoint. Complete → Session Summary; do not jump straight to Home.

06 · Writing Evaluation

State: practicing → reviewing · Intent: know which error to fix first

EVAL
EvidenceShow the learner's excerpt/answer first.
Feedback + confidenceIssue → why → suggested fix; distinguish certainty from items needing review.
Lưu lỗi này để ôn tập→
Low confidence → show evidence and mark incorrect feedback. Save → Mistake Notebook + FSRS queue.
Kết quảĐộ tin cậy thấpKhông có đánh giáThử lại

07 · Review Queue / Mistake Notebook

State: reviewing · Intent: remember and fix the right error

REVIEW
Queue priorityDue → weak skill → exam relevance; show the estimated duration.
Review cardRecall first, reveal the answer afterward; includes Again / Hard / Good / Easy.
Bắt đầu 7 mục đến hạn→
Queue empty → explain the next review and suggest a related practice task.

08 · Mock Test / Exam Mode

State: assessing · Intent: measure ability under exam conditions

TEST
Mode contractTimer, section order, no hints, confirm before submit.
Recovery checkpointShow the last saved state; resume without losing answered questions.
Tiếp tục bài kiểm tra→
Submit/timeout → Result Analysis. Network loss → preserve state and allow resume; do not create a duplicate submission.

09 · Result Analysis / Exam Readiness

State: ready-check · Intent: know what is missing before exam day

BAND
Overall + per skillBand range, confidence, and risk; do not present false precision.
Priority next stepsWeak-skill queue, targeted lesson, or next mock test.
Ôn Task Response trước→
Readiness changes after assessment/review; Home and notifications should remind only meaningful actions.

10 · Recovery / Account / Access

Cross-cutting states: offline, locked, inactive, blocked

SYSTEM UX
OfflineKeep local content and report which actions have not synced.
Locked/PremiumState access rights and a suitable alternative; do not block the entire learning loop.
InactiveInvite a micro-session; do not use guilt or streak pressure.
BlockedExplain the error, retry/contact options, and preserve learner data.
Every recovery preserves restorable context, input, and progress.

Journey • Daily Learning · Horizon reference

The daily learning loop should answer quickly: where do I start today?

This journey connects Home → Study Session → Session Summary → Next Best Action. The goal is a steady, manageable learning rhythm that always shows progress. This is a horizon reference; P0 build input uses `STUDY.DailyPlan` + `STUDY.MicroSession` in the Daily Action slice and does not use a P1 screen as a build-ready contract.

Main flow

1. Open HomeSee Today's Plan and one clear continue button.
2. Enter a study sessionThe timer, goal, and current task must always be clear.
3. Practice / learnLearn, practice, and review according to the personalized plan.
4. End the sessionA short summary: what you did, what improved, and what comes next.

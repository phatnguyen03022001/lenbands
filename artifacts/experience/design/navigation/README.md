# Navigation Design Artifacts

Dependency order:

```text
Information Architecture
        ↓
Navigation Model
        ↓
Learner Shell
        ↓
Journey Wireframes
```

- `information-architecture.md`: areas a learner can navigate to.
- `navigation-model.md`: header, sidebar, mobile navigation, and route-state logic.
- `learner-shell.html`: visual representation of the desktop header/sidebar, content frame, and mobile bottom navigation.

The shell is a presentation artifact; it is not Source Code or the Blueprint.

Mode variants (rail + stage)

This shell renders mode: core. For another mode, the cheap agent renders:

  • onboarding: rail only Today+Learn; stage = Welcome+baseline CTA; hide Tests/Practice/Review/More; no streak
  • early: rail Today+Learn+Practice+Review; hide Tests; stage = 1 micro-session+1 lesson; streak.zero when none exists
  • exam_prep: Tests+Review weighted, Learn dim; stage = exam readiness+risk+prioritized weak skill
  • comeback: Today only; stage = 1 light micro-session+non-guilt comeback copy; defer all drawers

Build rules (invariants)

  • 1 primary action per screen. Secondary actions recede.
  • No red badge. Change weight (.weighted/.dim) or use an accent dot.
  • Loop dots: done/now are clickable; future is not clickable.
  • Streak/Wellbeing must not create pressure.
  • Continue chip priority: mock > eval > session (only one at a time).
  • Mobile bottom nav has 5 items: Today/Learn/Practice/Review/More (More opens the Tests+Account sheet).

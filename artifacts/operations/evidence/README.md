# Bằng chứng

Bằng chứng là bản ghi bất biến hỗ trợ audit: license, permission, snapshot điều khoản, approval và checksum.

Đặt tên theo `{evidence_id}-{version_or_date}.{ext}`. Không overwrite file cũ; metadata hoặc decision artifact phải reference evidence ID và hash tương ứng.

Thư mục rỗng nghĩa là **chưa có evidence thật để lưu**. Không tạo PDF/email/run record giả chỉ để lấp folder. Khi có license clearance, benchmark run, procurement review, release record hoặc incident thật, lưu bản gốc tại đây kèm metadata/provenance theo Constitution.

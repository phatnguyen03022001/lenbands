# BOPS

BOPS means **Business / Operations / Platform / Security**.

This folder intentionally has only two authorities:

- `contract.yaml` — machine-readable controls and provider/data boundaries.
- `threat-model.md` — adversarial/interference analysis and red-team acceptance.

Provider pricing snapshots, benchmark runs, incidents and release evidence belong in their existing evidence/decision locations and are referenced from here. They are not copied into BOPS.

`../bops-contract-pack.md` is a migration-era provider monolith and is not the current authority. `DOCS.yaml` defines the alias.

# Artifact Templates

These templates are copy-forward scaffolds for the founder/agent. They are not the product SSOT; an artifact created from a template gets its own `derived_from`, owner, version, and lifecycle.

| Template | Use when |
|---|---|
| `vertical-slice-spec.md` | Preparing to build an end-to-end capability/journey |
| `screen-spec.md` | A screen needs a clear behavior/UI contract |
| `engineering-contract.md` | Preparing an OpenAPI, data/event/failure/prompt contract |
| `decision-record.md` | A decision has long-term, cross-domain, or hard-to-reverse effects |

Do not create an artifact from a template without a Capability ID or valid product decision for `derived_from`.
